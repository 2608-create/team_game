# PRO 아케이드 스포츠 센터

큐와 다트의 움직임을 웹에서 먼저 체험하는 스포츠 게임 프로토타입입니다. 현재 게임 입력은 마우스와 터치를 사용하며, ESP32 센서와 온라인 대전은 아직 연결되지 않았습니다.

## 지금 플레이할 수 있는 기능

- **포켓볼 연습:** 15개 공이 놓인 테이블에서 방향, 샷 파워, 큐볼 당점을 조절합니다. 일반 공은 100점, 8번 공은 150점, 수구 파울은 50점이 감점됩니다. 정식 8볼 턴·그룹 배정 규칙은 아직 적용하지 않습니다.
- **다트 연습:** 실제 다트보드의 숫자 배열과 싱글·더블·트리플·불스아이 점수 구역을 사용합니다. 한 라운드에 세 번 던집니다.
- **기록과 리더보드:** 닉네임과 점수를 저장하고 종목별 상위 5개 기록을 봅니다. 기록은 서버의 data/scores.json에 저장됩니다.
- **센서 미리보기:** 플레이 입력을 파워·조준 각도·스핀 값으로 표시합니다. 실제 MPU6050 또는 ESP32 센서 측정값은 아닙니다.

## 실행 방법

1. Node.js 18 이상을 설치합니다.
2. 프로젝트 폴더에서 npm install을 실행합니다.
3. npm start를 실행합니다.
4. 브라우저에서 http://localhost:3000을 엽니다.

기본 포트는 3000입니다. 다른 포트는 PORT 환경 변수로 지정할 수 있습니다. 기록 파일 위치를 바꾸려면 DATA_DIR 환경 변수를 사용하세요.

## 조작 방법

### 포켓볼

- 테이블에서 포인터를 움직여 조준합니다.
- 포인터를 누른 채 조준 방향의 반대로 당겼다가 놓으면 샷이 나갑니다.
- 오른쪽 컨트롤에서 파워를 정하고 **샷 실행**을 눌러도 됩니다.
- 당점 원을 누르거나 드래그해 큐볼 스핀을 조절합니다. 원을 선택한 뒤 방향키로도 이동할 수 있습니다.
- 캔버스에 포커스가 있을 때 방향키로 조준을 조금씩 움직이고 Enter 또는 Space로 샷을 할 수 있습니다.

### 다트

- 과녁의 원하는 위치를 클릭하거나 터치합니다.
- 오른쪽의 **다트 던지기** 버튼 또는 Enter 키로도 던질 수 있습니다.
- 세 번 던진 뒤 **새 라운드**를 눌러 다음 라운드를 시작합니다. 점수는 게임을 초기화할 때까지 누적됩니다.

## API

- GET /api/health — 서버 상태와 현재 저장 방식 조회
- GET /api/scores/POOL — 포켓볼 상위 5개 기록 조회
- GET /api/scores/DART — 다트 상위 5개 기록 조회
- POST /api/scores — 점수 기록 저장

점수 저장 요청 예시:

    {
      "username": "초고수",
      "game_type": "POOL",
      "score": 350
    }

닉네임은 1~16자, 점수는 1~100,000점의 정수만 허용합니다. 이 프로토타입은 계정 인증이나 부정 점수 방지 기능을 제공하지 않으므로 공개 운영 서비스의 랭킹으로 사용하기 전에 인증, 저장소, 요청 제한을 추가해야 합니다.
